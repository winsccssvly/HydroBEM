# Security

HydroBEM is a numerical library: it reads mesh files and solves problems on
the local machine and opens no network connections. If you find a problem
that could affect users' systems (for example a crash or memory error from a
crafted input file), please report it privately to the maintainer through
the repository's private vulnerability reporting (GitHub: *Security* →
*Report a vulnerability*) rather than in a public issue; while that is not
available, open an issue that only asks the maintainer for a private contact,
without the details. Reports are
acknowledged within two weeks.
